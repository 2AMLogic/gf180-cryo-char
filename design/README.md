# Design sources

The [ring-oscillator level shifter](ro-crossing/README.md) includes the transistor schematic, routed GF180D cell and extracted simulation netlist for the ring-to-divider crossing.

The [three oscillator layouts](rings/README.md) provide the 143-stage cores for the eight physical ring specimens, with full native DRC, transistor LVS and extracted receiver measurements.

The [oscillator readout switch](ro-isolation/README.md) compares physical read and current-measurement modes with the bare cores and records the VRO points that exceed the current allowance.
